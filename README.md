# Search Form Airport — Автокомплит для формы поиска аэропортов

**JavaScript-модуль для Drupal** — умный автокомплит с динамическим переключением между поиском аэропортов и городов.

## 🎯 О проекте

Кастомное JavaScript-решение для коммерческого проекта логистической компании. Добавляет интеллектуальный автокомплит в Drupal-форму поиска транспорта с поддержкой:

- ✈️ Поиска аэропортов (по названию и IATA-коду)
- 🏙️ Поиска городов и стран
- 🔄 Динамического переключения между типами транспорта
- 🎨 Адаптивного UI (placeholders, background)

**Использовался в production** на сайте грузоперевозок.

## 🛠 Стек

- **JavaScript (Vanilla + jQuery)** — логика автокомплита
- **Drupal 10** — интеграция с формами
- **CSS3** — стилизация выпадающего списка
